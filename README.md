# Shazam Sync

כלי דפדפן בודד (קובץ HTML אחד) שעוזר להעביר שירים שתייגת ב-Shazam אל Liked Songs
ב-Spotify. אין שרת, אין התקנה, אין חשבון מפתח נדרש - הכל רץ בג'אווהסקריפט בתוך
הדפדפן שלך.

## איך זה עובד

Shazam לא חושף API ציבורי לתגיות שלך, ואין דרך חינמית לגשת אליהן אוטומטית (הדרך
היחידה - Apple Music API - דורשת חשבון Apple Developer בתשלום, 99$/שנה). לכן הכלי
עובד הפוך: **את/ה מדביק/ה את רשימת השירים** (מהאפליקציה של Shazam - "My Shazam",
או מ-Apple Music אם יש לך), שורה לכל שיר בפורמט `שם השיר - אמן`.

לכל שיר ברשימה הכלי:
1. מחפש אותו ב-Spotify (fuzzy matching על שם+אמן).
2. בודק אם הוא כבר ב-Liked Songs שלך.
3. מציג כפתור **"+ הוסף"** ליד כל שיר שנמצא ועדיין לא קיים - לחיצה עליו מוסיפה
   אותו ל-Liked Songs מיידית. שירים שכבר קיימים או שלא נמצאו מסומנים בהתאם ולא
   ניתנים ללחיצה.

שום דבר לא נוסף בלי לחיצה מפורשת על שיר ספציפי, והכלי אף פעם לא מוחק או מסיר
שירים - רק מוסיף.

## דרישות מוקדמות

### Spotify (חינם)
1. היכנס ל-[developer.spotify.com/dashboard](https://developer.spotify.com/dashboard)
2. צור אפליקציה חדשה
3. ב-Redirect URIs הוסף את הכתובת שבה תארח את `index.html` (למשל כתובת GitHub Pages)
4. שמור את ה-Client ID (לא צריך Client Secret - הזרימה היא PKCE, בטוחה גם בצד לקוח)

זהו - אין דרישות נוספות. אין צורך בחשבון Apple Developer.

## איך מריצים

Spotify דורש ש-Redirect URI יהיה כתובת http/https אמיתית (לא ניתן להשתמש בקובץ
מקומי `file://`), אז צריך לארח את `index.html` איפשהו עם https. הכי פשוט וחינמי:
**GitHub Pages**.

```bash
# בתוך תיקיית הפרויקט
git init
git add index.html README.md
git commit -m "Shazam Sync"
git remote add origin https://github.com/<your-username>/shazam-sync.git
git push -u origin main
```

ואז ב-GitHub: Settings → Pages → Deploy from branch → main. הכתובת שתקבל
(`https://<your-username>.github.io/shazam-sync/`) היא זו שרושמים ב-Spotify
כ-Redirect URI, ופותחים בדפדפן כדי להשתמש בכלי.

## שימוש

1. פתח את הדף, מלא Client ID ולחץ "התחבר ל-Spotify".
2. פתח את אפליקציית Shazam בטלפון ← My Shazam (הספרייה שלך), והקלד/העתק לתיבת
   הטקסט שורה לכל שיר: `שם השיר - אמן`.
3. לחץ "טען שירים" - הכלי יחפש כל שיר ב-Spotify ויבדוק מול ה-Liked Songs שלך.
4. לחץ "+ הוסף" ליד כל שיר שרוצים להוסיף.

ה-Spotify token מתחדש אוטומטית, כך שבדרך כלל לא תצטרך/י להתחבר מחדש בכל פעם.

## מגבלות ידועות

- הכלי אף פעם לא מוחק או מסיר שירים - רק מוסיף, ורק אחרי לחיצה מפורשת על כל שיר.
- בדיקת הכפילויות בודקת רק מול Liked Songs (לא מול פלייליסטים אחרים).
- ההתאמה ל-Spotify מבוססת על השוואת שם+אמן מטושטשת (fuzzy matching) - יכולות להיות
  התאמות שגויות נדירות עבור remixes/covers עם שמות דומים מאוד, או אי-התאמות אם
  הפורמט של השורה לא כולל מפריד ` - ` ברור בין השם לאמן.
- אין דרך אוטומטית לקבל את רשימת השירים מ-Shazam - זו הדבקה ידנית, כי אין API
  חינמי לכך.
